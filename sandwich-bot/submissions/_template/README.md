# New submission

1. Copy this folder to the next free ID: `sub-002`, `sub-003`, ...
   IDs only. No student names anywhere in this repo (it is public).
2. `transcription.md`: the exact words, typos and all. Never commit photos.
3. `script.json`: replace the steps. `text` is the student's words exactly.
4. `log.md`: one row per step, what the robot does and why.
5. Add the ID to `apps/platform/src/lib/sandwich-bot/submissions.ts`.
6. Credit: add `"sub-002": "J.K."` to the `SANDWICH_BOT_CREDITS` setting in Vercel.
