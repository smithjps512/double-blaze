  product plans for the same product, one per student. The plan in this folder
  is the union of all three, using their sentences.
- `My User Stories.pdf` through `My User Stories5.pdf`: five user stories, one
  per student. Sign-in, sell, map, buy, health AI.

Changes made in transcription: spelling corrected, the fill-in-the-blank
template scaffolding removed (`As a…[type of user]`), student first names
removed, and a chat transcript that had been pasted into the end of
`Product Plan3.pdf` dropped.

Nothing was added. Missing "so that" clauses and missing Then clauses were left
missing, so the coach notes in the prototype are true.
