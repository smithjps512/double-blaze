# AI Room Arranger user stories

Team: Nyktilathraiophagos Productions

## Scan system

As a creator user, I want to be able to scan my room, so that I can be ready to
move the furniture.

  - Be able to scan and show the furniture clearly
  - All furniture must look as it does in the actual room
  - Must be able to successfully add and subtract
  Given to rearrange my room I need to scan my room
  When I scanned it and the scan got put into the AI
  Then the AI made an interactive 3D view of my room that I can use to rearrange it

## AI recognition

As a user, I want to make it so an AI can recognize objects, so that I can select
each object and move it anywhere around the room.

  - Create the AI
  - Teach it to recognize objects
  - Test and improve it a countless number of times
  Given I just moved into a new house
  When I tried to get all of my stuff from my old house organized to my liking
  Then I used the AI room designer and found how I wanted my house to look and where I wanted my stuff to go

## Sign in

As a consumer user, I want to be able to make an account, so that I can save all
the rooms I have pictured.

  - Must put in email or phone number
  - Username must be unique
  - Passwords must be eight characters long and have uppercase and lowercase letters
  Given I need to access a room I already recorded
  When I logged into my account
  Then I was able to access the room and rearrange things again
