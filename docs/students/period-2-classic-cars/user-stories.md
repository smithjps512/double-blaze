## Quiz mode

As a user, I want to make the quiz mode, so that I can get people to test their
knowledge about the car they learned about.

  - I must be able to put the questions in the quiz
  - I must know what the answers are so I can pick which questions are correct
  - I must be able to make it so that you can submit it
  Given I am making the quiz
  When I add the questions to the quiz
  Then I make a submit button and can turn it in
