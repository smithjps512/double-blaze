# GAMEHACK user stories

Team: GameHack

## Tutorials

As a gamer, I want to have simple and easy tutorials, so that I can have an
easier time playing video games.

  - You must be able to follow the tutorials that we have linked in the app

As a gamer and coder, I want to have an easy way to help people with video
games, so that me and others can have a funner time playing video games.

  - You must be able to follow tutorials linked in the app and know how to ask the AI
  Given you need to beat a specific boss or find a specific thing in the game
  When you need help and need to pass a stage
  Then you can play easier

## AI

As a video game tutorial app, I want the AI to calculate methods and tutorials
about specific hard or challenging parts, so that people can get easy access to
parts that they might be stuck on.

  - We must figure out how to correctly code the AI to give suggestions based on the game and version
  Given the app stops working
  When people are currently using it
  Then we will have a report glitch button that anyone can use
