## Card 1: Find a tutorial

**Your story.** As a gamer, I want simple and easy tutorials, so that I can have
an easier time playing video games.

**Done when:**
- [ ] Every game with tutorials appears in a list
- [ ] Clicking a game shows its tutorials
- [ ] Each tutorial shows a title and a link

**Build it:** Architecture, Feature 1. Build this first.

---

## Card 2: Search for my game

**Your story.** As a gamer, I want to search for the game I am stuck on, so that
I do not have to scroll through everything.

**Done when:**
- [ ] Typing a game name and searching shows that game
- [ ] Searching for something that is not there says so

**Build it:** Architecture, Feature 2.

---

## Card 3: Add a tutorial

**Your story.** As a gamer and coder, I want an easy way to help other people
with video games, so that we all have a better time playing.

**Done when:**
- [ ] You can pick a game and add a tutorial title and link
- [ ] Submitting with an empty link is refused
- [ ] The new tutorial appears under that game straight away

**Build it:** Architecture, Feature 3.

---

## Card 4: Ask the helper

**Your story.** As a gamer stuck on a hard part, I want to ask a question and
get advice, so that I can get past it.

*(Your story was written as "As a video game tutorial app, I want the AI to...".
An app is not a person. Whoever is stuck on the boss fight is the person, and
this is their story.)*

**Done when:**
- [ ] Asking a question gives an answer
- [ ] A question with no matching answer says so instead of guessing
- [ ] The answer appears on the screen, not in the output panel

**Build it:** Architecture, Feature 4.

---

## A note for the whole team

**Your three stories describe two different apps.** One of you wrote that
GAMEHACK is just links to tutorials with no scenarios. The other two wrote about
an AI that works out methods for specific hard parts. Both are reasonable
products. They are not the same product, and you cannot build both.

Settle it in the first five minutes of the next class. It is the most important
decision in front of you and it costs one conversation.
