# Where this team's documents came from

Transcribed from Google Drive, folder `1st Period stories / 1st period stories
and plan`.

The team is BMS Crew, the first class to start the unit. The name was given by
the teacher: the students never named themselves, because there is no plan
document where a team name would have gone.

Six user story templates were handed in, one per student, and the product name
comes from inside the stories rather than from a plan.

- Four templates were filled in: signing up, weather, activity tracker,
  chatroom.
- **Two were handed in completely blank**, still holding the placeholder text
  (`As a…[type of user]`). They are not represented here, because there is
  nothing in them.

Student names were in the file names and have been removed. Spelling was
corrected and the template scaffolding was dropped.

---

## The product plan, handed in later

`Strive Fitness Product Plan.pdf`, handed to the teacher after the stories.

**Five students' first names have been removed.** In the handed-in file the
features were grouped under the name of whoever wrote each one, as a column of
headings down the left. That is a record of who did what, which is a real and
useful thing in a team, and it is not something to publish: this repository is
public and the site built from it is open to anybody. The features are here in
the order they were written, without the names above them.

**Nothing else was cut and nothing was added.** Spelling and punctuation were
corrected. The benefit each student wrote for their feature was folded into the
same paragraph as the description, because the plan template has one line per
feature rather than a table with two columns.

**Three headings were handed in empty and are still empty here:**

- **Product description.** The heading was there with nothing under it.
- **Content curator** and **Content creator**, two of the three kinds of user.
  They were named and never described.

Leaving them blank is deliberate. The prototype reports what is missing from a
plan, and quietly filling a gap in would make the report a lie. All three are on
the team's What next page now, which is where they should be.
