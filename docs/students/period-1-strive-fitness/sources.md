# Where this team's documents came from

Transcribed from Google Drive, folder `1st Period stories / 1st period stories
and plan`.

The team is BMS Crew, the first class to start the unit. The name was given by
the teacher: the students never named themselves, because there is no plan
document where a team name would have gone.

The folder is named "stories and plan" but contains **no product plan**. Six
user story templates were handed in, one per student, and the product name
comes from inside the stories rather than from a plan.

- Four templates were filled in: signing up, weather, activity tracker,
  chatroom.
- **Two were handed in completely blank**, still holding the placeholder text
  (`As a…[type of user]`). They are not represented here, because there is
  nothing in them.

Student names were in the file names and have been removed. Spelling was
corrected and the template scaffolding was dropped. Nothing was added, so the
missing plan stays missing in the prototype.
