# Day 4: Make it yours, and name it

No em dashes anywhere in this document or any copy it generates.

At the end of today, every layer that will be built has the name the design
brief gives it, the screen's bad day is drawn beside its good day, and the
file has one colour, two text sizes and one gap, written down.

## Again (5 minutes)

From memory, faster:

1. Card, brief and Figma open. Go down the Done when list once. Every line
   still on the screen? Anything crept back on that is not on the card?

## Watch (5 to 10 minutes)

1. **Click** a layer on the Bus Buddy screen and show its name: Frame 214.
   Open the brief's component list beside it. **Rename** it to the brief's
   name for that thing, exactly, prefix and all. Do three. Say: the builder
   has this list. A layer with the brief's name is a layer they can find. A
   layer called Frame 214 is one they will build wrong or not at all.
2. **Duplicate** the frame and name the copy the screen name plus `/ empty`.
   Delete the list in it and write, in real words, what the screen says when
   there is nothing yet. Say: the empty state is the first thing every user
   sees, and the AI never draws it. Do `/ error` the same way with one honest
   sentence.
3. **Pick one colour.** Write its hex code on the Cover page. Set the biggest
   text and the body text and nothing in between. Pick one gap and use it
   between every pair of things. Say: not pretty, on purpose. Three decisions
   and the screen looks designed. Thirty and it looks like a ransom note.
4. **Ask** the **I am designing in Figma** tab one question you actually have,
   like "does Anvil have a toggle" or "what do I call the list row". Read the
   answer. Say: it has the brief. Ask it about names.
5. **Go down** the "Before you hand it over" list on
   [Start with AI](/build/figma-ai.html) out loud, ticking.

Say out loud: yesterday the AI made a picture. Today it became a design,
because a design is a set of decisions somebody else can follow.

## Do (25 to 30 minutes)

1. *(again)* Done when, once, against the frame.
2. **(today)** Rename every layer that will be built to its name from the
   design brief. Exactly. Prefix and all. Anything still called Frame,
   Rectangle or Text is either renamed or deleted.
3. **(today)** Draw `/ empty` beside your frame, with the real words the screen
   shows when there is nothing. Draw `/ error` with one honest sentence.
4. **(today)** One colour, hex written on the Cover page. Two text sizes. One
   gap. Fix the frame to match.
5. **(today)** Real words everywhere. If a name or a number on the screen is
   not in your story or your plan, it goes.
6. **(today)** Make the Cover page: product name, team name, what it is for,
   the hex code, the fonts. No student names on it, ever.
7. **(today)** Go down "Before you hand it over" on
   [Start with AI](/build/figma-ai.html). Every line ticked, or you know why
   not.

Stuck? Rule 2 and rule 5 on [Designing for Anvil](/build/figma.html) are
today. The **I am designing in Figma** tab knows both.

## Done when

Every built layer named from the brief, `/ empty` and `/ error` beside the
frame, a Cover page with one hex code on it, and the checklist ticked.

## Tomorrow adds

Handing it over. Sharing the file from your design brief, the review that
reads it against your documents, and fixing the first thing it finds.
