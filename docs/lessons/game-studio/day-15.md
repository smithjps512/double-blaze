# Day 15: Definition of Done review, and design doc v1

No em dashes anywhere in this document or any copy it generates.

At the end of today, every level is done and the studio's design doc v1 is turned in for the Double Blaze build.

## Again (5 minutes)

1. Say the four parts of the Definition of Done from memory: who, what and
   why; at least 2 checks; a happy path; a bad day.

## Watch (5 to 10 minutes)

The teacher does this on the projector, start to finish. Nobody types until it
is done.

1. **Open** Demo Studio's **Level up** tab. Read the to-do list out loud.
   Fix one item on the projector. Show it disappear.
2. **Open** the **Design doc** tab. Scroll through the whole doc: pitch,
   players, loop, world, mechanics, levels. Say: this is exactly what Double
   Blaze will build from. Nothing else.
3. **Read** one level out loud the way a builder would: slowly, literally.
   Point at one place where a builder would have to guess. Fix it.
4. **Explain** the weekend: you export every studio's doc tonight and the
   games are built from it. They will see v1 on /play on day 21.

Say out loud: if it is not in the design doc, it is not in the game. Today is the last chance to put it there.

## Do (25 to 30 minutes)

1. *(again)* Open your studio. Open Level up.
2. **(today)** Work down the Level up list until every level is green. Split
   it: each role takes one level.
3. **(today)** Open the Design doc tab. Read the whole thing out loud, one
   person per section.
4. **(today)** Mark every place a builder would have to guess. Fix each one.
5. **(today)** The Producer tells the teacher: "Our design doc v1 is done."

Stuck? Level up lists every gap, in order. Do the first one, then the next.

## Done when

Every level in the studio's design doc is green, and the Producer has told the teacher it is ready.

## After class

Run `npm run studio:export` to write every studio's doc to the repository,
then build v1 for each studio over the weekend. Builds go on
[/play](https://doubleblaze.solutions/play) by day 21. Build only what the doc
says; where it is thin, the game is thin, and that is the lesson for week 5.
