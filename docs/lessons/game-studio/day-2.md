# Day 2: The core loop in games they know

No em dashes anywhere in this document or any copy it generates.

At the end of today, every student can find the core loop of a game they know and name the one verb the game cannot live without.

## Again (5 minutes)

1. Name the four studio roles without looking at the cards.
2. Draw yesterday's loop again from memory, faster.

## Watch (5 to 10 minutes)

The teacher does this on the projector, start to finish. Nobody types until it
is done.

1. **Draw** three loops on the board for games most of the class knows, asking
   the class for the verbs: a block building game (gather, build, explore,
   survive), a racing game (steer, boost, pass, finish), a runner (run, jump,
   collect, dodge).
2. **Cross out** one verb from the runner, "jump". Ask: is it still the same
   game? It is not. Say: that is the **core verb**. Circle it.
3. **Cross out** "collect" instead. Ask again. It still mostly works. Say: so
   collect is not the core verb, it is an extra. Extras can come later.
4. **Add** how you win and how you lose under each loop. Say: the loop is what
   you do, win and lose are why it matters.

Say out loud: every game has one verb it cannot live without. Find it first, and protect it.

## Do (25 to 30 minutes)

Same pairs as yesterday.

1. *(again)* Draw yesterday's loop from your notes. Check the feeling is still
   one word.
2. **(today)** Pick two games you both know well. Draw a loop for each, 3 or
   4 verbs.
3. **(today)** For each loop, cross out verbs one at a time. Circle the core
   verb, the one that breaks the game when it goes.
4. **(today)** Under each loop, write how you win and how you lose.
5. **(today)** Start a third loop for a game that does not exist yet. Just the
   verbs. It is fine if it is silly.

Stuck? If every verb seems important, ask: which one does the player do the most times in one minute?

## Done when

Every pair has three loops, each with a circled core verb and a win and a lose under it.
