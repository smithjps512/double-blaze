# Day 19: One mechanic from your own design doc

No em dashes anywhere in this document or any copy it generates.

At the end of today, every studio has built one mechanic from its own Mechanics tab, exactly as the rule says.

## Again (5 minutes)

1. Show your tilemap level with the camera following and one check built.

## Watch (5 to 10 minutes)

The teacher does this on the projector, start to finish. Nobody types until it
is done.

1. **Open** Demo Studio's Mechanics tab. Read the rule for "Jump": "Bolt jumps
   3 tiles high. Holding A does not jump higher."
2. **Build** it, talking through each block: gravity with **set mySprite ay
   to** in on start; **on A button pressed**; set vy so the jump is about 3
   tiles. Test it against a 3 tile wall and a 4 tile wall.
3. **Show** where the rule was not enough: "Can Bolt jump in mid air?" The
   rule does not say. Say: building it is how you find out what the doc
   forgot. Write it down.

Say out loud: building one mechanic exactly as written is the fastest way to find out if you wrote it well.

## Do (25 to 30 minutes)

As a studio. The Developer drives, everyone helps. Others may copy it into
their own projects.

1. *(again)* Open a working project with a moving hero and a tilemap.
2. **(today)** Pick ONE mechanic from your Mechanics tab. Usually your core
   verb.
3. **(today)** The Producer reads the rule out loud, one sentence at a time.
   The Developer builds only what was read.
4. **(today)** Every time the rule does not say what to do, stop and write the
   question on a sticky note. Do not guess quietly.
5. **(today)** Share the project link with the studio (Share button, top).

Stuck? Read the rule for numbers: speed, height, time. Each number is a block setting somewhere.

## Done when

Every studio has one mechanic built from its own rule, and a list of questions the rule did not answer.

Test your mechanic against your own checks, and fix the design doc.
