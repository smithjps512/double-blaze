# Day 9: Mechanics, with controls and rules

No em dashes anywhere in this document or any copy it generates.

At the end of today, every studio has at least 3 mechanics, each with a name, controls and a rule that says what happens.

## Again (5 minutes)

1. Read your story intro out loud.
2. Name the core verb, and say why the hero does it.

## Watch (5 to 10 minutes)

The teacher does this on the projector, start to finish. Nobody types until it
is done.

1. **Open** Demo Studio's **Mechanics** tab. Add one: name "Jump",
   controls "A button", rule "Bolt jumps 3 tiles high. Holding A does not jump
   higher." Say: a rule says exactly what happens.
2. **Add** "Magnet pull": controls "none", rule "Within 4 tiles of a magnet,
   Bolt slides toward it at half speed." Say: some mechanics are not buttons.
   They are rules the world follows.
3. **Show** a weak one: name "Cool power", rule "does something awesome". Ask
   what a builder would build from that. (Nothing.)
4. **Say** the test for a rule: two people reading it would build the same
   thing.

Say out loud: a mechanic is a verb with a rule. If two builders would build it two different ways, the rule is not finished.

## Do (25 to 30 minutes)

1. *(again)* Open your studio. Check World and Core loop. Fix anything the
   last two days changed.
2. **(today)** Mechanics tab: one mechanic for every verb in your core loop.
   Name, controls, rule.
3. **(today)** Add at least one rule the world follows that is not a button
   (gravity, enemies, a timer).
4. **(today)** The Developer reads each rule and draws what they would build
   on paper. The Game Designer says if the drawing is right.
5. **(today)** Any rule the Developer drew wrong gets rewritten. Use numbers:
   how high, how fast, how many.

Stuck? Put a number in every rule: tiles, seconds, hearts, points.

## Done when

Every studio has at least 3 mechanics, each with controls and a rule that has a number or a clear yes or no in it.
