# User stories for Find your way

Team: Da purples

## School navigation

As a new student, I want to be able to easily find my class and not be late, so that I can learn and not be stressed.

  - New students can find their classes on time without getting confused

## School navigation

As a teacher, I want to have my students in class on time and learning, so that they can learn and be their best self.

## Packed hallways

As a student, I want to know how crowded it is in the hallways and how much time I have before the bell rings, so that I can be in class on time and not have to push through crowds.

## Scan my schedule

As a student, I want to take a picture of my schedule and have it sync up, so that I can use my schedule.
