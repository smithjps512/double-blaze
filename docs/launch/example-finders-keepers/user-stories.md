# User stories for Finders Keepers

Team: Example Team

## Photo search

As a student, I want to look through photos of everything turned in this week, so that I can find my jacket before it gets donated.

  - Every item has a photo
  - The newest items show first
  - I can tell where to pick it up

## Post a found item

As a front office staff, I want to snap a photo of a found item and post it in under a minute, so that the pile does not take over the office.

## Name alert

As a parent, I want to get a message when something with my kid's name on it is turned in, so that I can stop buying replacements.

## Drop-off spots

As a custodian, I want to see the closest drop-off bin on my floor, so that I can hand things in without walking to the office.
