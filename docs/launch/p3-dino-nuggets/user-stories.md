# User stories for Weightin

Team: dino nuggets

## Stat tracker

As a body builder, I want to have something to track my exercise and calories, so that I can train without worrying about tracking stats.

## Food and exercise balancer

As an overweight person, I want to lose weight, so that I can be fit and be more attractive.

## Sports trainer

As a football player, I want to be able to tackle more people and be faster, so that I can win games and catch up with people.
