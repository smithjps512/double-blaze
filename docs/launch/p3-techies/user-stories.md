# User stories for The Homework Helper

Team: techies

## Homework Helper

As a student, I want to have an app that can help me with my work, so that I can get better grades.

## Homework Helper

As a teacher, I want to help students understand their work better (we can even block it if we do not think they need the help), so that I don't have to help every individual student with their work.

## Parent helper

As a parent, I want to help my children with their work without having to relearn the new style of work, so that I can feel successful.
